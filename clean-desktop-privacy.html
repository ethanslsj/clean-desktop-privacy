隐私政策 · 简洁桌面（QingjieDesktop）

发布者：ethan_slsj  ·  生效日期 / 最后更新：2026-09-23

我们收集什么

不收集任何个人数据。

简洁桌面是一款完全运行在你本地电脑上的桌面启动器。它：

  • 不会上传、不会向任何服务器发送你的文件、设置或使用行为；
  • 不会要求登录账号，不集成任何广告或统计分析 SDK；
  • 不会主动访问网络（仅在你在应用内主动点击网址时，调用系统默认浏览器打开该网址）。

数据存于何处

所有数据仅保存在你本机：

  • 设置（专注记录、任务、常用网址、壁纸偏好等）写入本机用户目录下的 settings.json；
  • 应用会在本地扫描你指定的文件夹（桌面、文档、下载、图片、音乐、视频）用于本地搜索；索引仅驻留内存，不落盘、不上传；
  • 退出时清理自身产生的临时解包残留（仅删除能确认属于本应用的目录）。

所需系统能力说明

为提供本地文件搜索功能，应用在 Microsoft Store 包中声明了 broadFileSystemAccess（广泛文件系统访问）受限能力，用于读取上述已知文件夹以建立本地文件名索引。该访问仅在本机进行，索引数据不上传任何服务器。你可以随时在 Windows 设置中撤回该权限，届时文件搜索功能将不可用（其余功能不受影响）。

第三方

无。应用不调用任何第三方服务、不嵌入任何跟踪脚本、不与任何第三方共享或出售数据。

儿童隐私

本应用不面向儿童设计，也不会有意收集儿童的任何信息（事实上不收集任何人的信息）。

政策变更

若本政策发生变更，将更新本页顶部的「最后更新」日期。由于应用不收集数据，变更预计仅涉及文字表述。

你的权利

由于数据从不离开你的设备，你随时可删除本应用或其用户数据目录来彻底清除全部本地数据。

English Summary

Clean Desktop (QingjieDesktop) does not collect any personal data.

  • All settings, tasks, focus records and search indexes stay on your device. Nothing is uploaded to any server.
  • The app contains no advertising, analytics or tracking SDKs, and makes no network requests on its own (links you click are opened by your system browser).
  • The Microsoft Store package declares the restricted capability broadFileSystemAccess solely to index filenames in your own Desktop / Documents / Downloads / Pictures / Music / Videos folders for local search. The index is kept in memory and never uploaded.
  • You can revoke that permission at any time in Windows Settings; only the file-search feature would stop working.
